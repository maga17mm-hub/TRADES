# 📈 TradeLog — Дневник Трейдера (PWA)

Современное мобильное веб-приложение (Progressive Web App) для ведения профессионального торгового журнала с поддержкой офлайн-режима, прикрепления скриншотов графиков, глубокой аналитики сетапов и структурирования по месяцам.

Дизайн разработан в стиле современных финтех-платформ (**Polar.sh** / **Refero**): темная глубокая тема, неоновые акценты, стеклянные карточки и удобное жестовое управление для смартфонов и ПК.

---

## ✨ Возможности приложения

1. **Запись и журнал сделок**:
   - **Инструмент / Тикер** (BTC/USDT, ETH/USDT, XAU/USD, EUR/USD и т.д.).
   - **Направление**: LONG (покупка) или SHORT (продажа).
   - **Таймфрейм (TF)**: 1m, 3m, 5m, 15m, 30m, 1h, 4h, 1D, 1W.
   - **Торговый сетап**: предустановленные SMC / Price Action сетапы (*Liquidity Sweep*, *FVG / Imbalance*, *Order Block*, *Breakout / Пробой*, *CHoCH / Слом*, *Support/Resistance*) + возможность вводить **свои сетапы**.
   - **Время и дата входа и выхода**: с быстрым выбором кнопки «Сейчас» и автоматическим подсчетом длительности нахождения в позиции.
   - **Цены входа и выхода** (опционально).
   - **Результат**: Тейк-профит (WIN), Стоп-лосс (LOSS) или Безубыток (BE) с записью PnL в R или валюте (например, `+3.2R` или `+$450`).
   - **Заметки и психология**: фиксация логики входа, соблюдения риск-менеджмента и эмоций.

2. **Прикрепление скриншотов графиков**:
   - Загрузка любого количества фото графиков к сделке (HTF старший контекст, LTF вход, результат).
   - Поддержка вставки из буфера обмена (**Ctrl+V** прямо на странице!).
   - Интеллектуальное клиентское сжатие картинок без потери четкости графиков.
   - Полноэкранный просмотр графиков (Lightbox / зум) по клику.
   - Надежное хранилище **IndexedDB** в браузере (не переполняет память в отличие от обычного LocalStorage и хранит сотни мегабайт графиков офлайн).

3. **Структурирование и аналитика**:
   - **Структурирование по месяцам**: интерактивные плашки месяцев и аккордеонная группировка сделок с подытогами за каждый месяц (количество трейдов, винрейт месяца, суммарный R).
   - **Структурирование по сетапам**: фильтрация в 1 клик для анализа того, какой сетап приносит больше всего профита, а какой дает убытки.
   - **Фильтры**: по таймфрейму, результату (только тейки / только стопы), направлению (Long/Short) и мгновенный поиск по активу или заметкам.
   - **Статистика в реальном времени**: общий винрейт, итоговый накопленный PnL, соотношение W/L/BE, лучший сетап.

4. **100% PWA (Офлайн и установка на телефон)**:
   - Работает без интернета через Service Worker.
   - Устанавливается на рабочий стол iPhone (iOS) и Android как полноценное приложение без рамок браузера.
   - Экспорт и импорт резервной копии (JSON): ваши данные всегда в безопасности и под вашим контролем.

## 🚀 Как выгрузить проект на GitHub и запустить в интернете

### Шаг 1. Создайте репозиторий на GitHub
1. Перейдите на [github.com](https://github.com) и войдите в свой аккаунт.
2. Нажмите зеленую кнопку **«New»** (или значок `+` в правом верхнем углу -> **New repository**).
3. В поле **Repository name** укажите название, например: `tradelog` или `trade-journal`.
4. Оставьте репозиторий **Public** (Публичным).
5. Поставьте галочку **«Add a README file»** (это создаст репозиторий сразу активным) и нажмите **«Create repository»**.

---

### Шаг 2. Загрузите файлы на GitHub

Вы можете загрузить проект любым удобным способом:

#### Вариант А (Самый простой — прямо через браузер, без установки программ):
1. В созданном репозитории нажмите кнопку **«Add file»** ➔ **«Upload files»**.
2. Откройте папку `trade-journal-pwa` на рабочем столе.
3. Выделите все файлы и папки внутри (`index.html`, `manifest.json`, `sw.js`, папки `css`, `js`, `icons`) и **перетащите их мышкой в окно браузера**.
4. Дождитесь загрузки полосы прогресса.
5. Внизу страницы нажмите зеленую кнопку **«Commit changes»**. Готово!

#### Вариант Б (Через терминал Git):
Если у вас установлен Git:
```bash
cd "%USERPROFILE%\Desktop\trade-journal-pwa"
git init
git add .
git commit -m "Initial commit: TradeLog PWA journal"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/tradelog.git
git push -u origin main
```


*(При первом пуше Git может попросить войти через браузер или ввести Personal Access Token).*

## 🌐 Как включить бесплатный хостинг (GitHub Pages)

Чтобы открывать приложение с любого телефона по персональной ссылке:

1. В вашем репозитории на GitHub перейдите во вкладку **Settings** (Настройки).
2. В левом меню нажмите **Pages**.
3. В разделе **Build and deployment** -> **Branch** выберите ветку `main` и папку `/ (root)`.
4. Нажмите **Save**.
5. Через 1-2 минуты обновите страницу. Сверху появится зеленая плашка со ссылкой на ваше приложение:
   `https://ваш-логин.github.io/tradelog/`

## 📱 Как установить TradeLog на телефон как приложение

### На iPhone (iOS Safari):
1. Откройте вашу ссылку GitHub Pages в **Safari**.
2. В нижней панели нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Прокрутите список и выберите **«На экран «Домой»»** (Add to Home Screen).
4. Нажмите **«Добавить»**. На экране iPhone появится фирменная иконка приложения. TradeLog будет запускаться на весь экран без адресной строки!

### На Android (Google Chrome):
1. Откройте ссылку в **Chrome**.
2. Нажмите на синюю плашку вверху экрана **«Установить»** или откройте меню (три точки в углу) и выберите **«Установить приложение»**.
3. Приложение появится в списке ваших программ.

## 💾 Резервные копии данных
Все сделки сохраняются в браузере вашего устройства. Чтобы обезопасить себя при очистке кэша или перенести историю сделок на другое устройство:
- Нажмите иконку **скачивания** в шапке приложения.
- Нажмите **«Скачать бэкап (JSON)»**.
- На новом устройстве выберите **«Восстановить из файла JSON»**.
